= Software Factory & Developer Experience
:navtitle: Software Factory & Developer Experience

Learning Objective

By the end of this module, learners will be able to:

Explain what a Software Factory is.
Describe how software moves from source code to production.
Understand how Red Hat OpenShift and Red Hat Advanced Developer Suite provide an opinionated Software Factory.
Explain the role of Dev Spaces, Developer Hub, and Golden Paths.
Recognize how Platform Engineering improves the developer experience.
