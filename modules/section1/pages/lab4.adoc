= Lab 4: Configure OpenShift OAuth Authentication
:navtitle: Lab 4: Configure OpenShift OAuth
:experimental:

In this lab, you'll replace the temporary Guest authentication used during installation with OpenShift OAuth authentication.

This allows developers to sign in using their OpenShift identities, providing a production-like authentication experience for Red Hat Developer Hub.

By the end of this lab, you will have:

* Created an OpenShift OAuth client
* Configured Developer Hub to authenticate using OpenShift OAuth
* Mounted authentication secrets into the Backstage application
* Verified user sign-in with OpenShift credentials
* Tested the Golden Path template using an authenticated user

== Configure Keycloak OAuth Authentication

Replace guest authentication with Keycloak OAuth for production-like access.

=== Create the Auth Secret

RHDH will need to sign/encrypt the session cookie used during the OIDC flow. We need to generate and define a session secret. It can be any string but for real use it should be high entropy, e.g. ~32 random bytes

[source,bash,role=execute,subs="attributes+"]
----
export SESSION_SECRET=$(python3 -c 'import secrets; print(secrets.token_hex(32))')
export GITLAB_URL="https://$(oc get route -n gitlab -l app=webservice -o jsonpath='{.items[0].spec.host}')"
export CLUSTER_DOMAIN=$(oc get ingresses.config.openshift.io cluster -o jsonpath='{.spec.domain}{"\n"}')

oc create secret generic rhdh-auth-secret -n setup-rhdh \
  --from-literal=KEYCLOAK_RHDH_REALM=etx-lab \
  --from-literal=KEYCLOAK_CLIENT_ID=rhdh \
  --from-literal=KEYCLOAK_CLIENT_SECRET=etx-lab-workshop-gitlab-secret \
  --from-literal=KEYCLOAK_BASE_URL=https://etx-sso.${CLUSTER_DOMAIN} \
  --from-literal=SESSION_SECRET=${SESSION_SECRET} \
  --from-literal=GITLAB_TOKEN=${GITLAB_PAT}
----

image::edit.png[link={imagesdir}/edit.png, width=400,window=_blank]

. Copy the output of the following command. This value is the **openshift_cluster_ingress_domain** and is required in the next step.
+
[source,yaml,role=execute,subs="attributes+"]
----
openshift_cluster_ingress_domain=$(oc get ingresses.config.openshift.io cluster -o jsonpath='{.spec.domain}{"\n"}')
echo ${openshift_cluster_ingress_domain}
----

. Replace the **Guest** authentication configuration with the following OIDC configuration, make sure to substitute **openshift_cluster_ingress_domain** with output receive from above command.
+
[source,bash,role=execute,subs="attributes+"]
----
    signInPage: oidc
    auth:
      environment: production
      session:
        secret: ${SESSION_SECRET}
      providers:
        oidc:
          production:
            clientId: ${KEYCLOAK_CLIENT_ID}
            clientSecret: ${KEYCLOAK_CLIENT_SECRET}
            metadataUrl: ${KEYCLOAK_BASE_URL}/realms/${KEYCLOAK_RHDH_REALM}
            prompt: auto
    catalog:
      providers:
        keycloakOrg:
          default:
            baseUrl: ${KEYCLOAK_BASE_URL}
            clientId: ${KEYCLOAK_CLIENT_ID}
            clientSecret: ${KEYCLOAK_CLIENT_SECRET}
            realm: ${KEYCLOAK_RHDH_REALM}
            loginRealm: ${KEYCLOAK_RHDH_REALM}
            schedule:
              frequency: { minutes: 5 }
    integrations:
      gitlab:
        - host: gitlab.{openshift_cluster_ingress_domain}
          token: ${GITLAB_TOKEN}
          apiBaseUrl: https://gitlab.{openshift_cluster_ingress_domain}/api/v4
          baseUrl: https://gitlab.{openshift_cluster_ingress_domain}
----

== Create Dynamic Plugins ConfigMap

Create a dynamic plugins ConfigMap to enable the Keycloak Org sync plugin and the gitlab scaffolder plugin for our template

[source,yaml,subs="attributes+",role=execute]
----
oc create -f - <<EOF
kind: ConfigMap
apiVersion: v1
metadata:
  name: dynamic-plugins-rhdh
  namespace: setup-rhdh
data:
  dynamic-plugins.yaml: |
    includes:
      - dynamic-plugins.default.yaml
    plugins:
      - package: './dynamic-plugins/dist/backstage-community-plugin-catalog-backend-module-keycloak-dynamic'
        disabled: false
      - package: './dynamic-plugins/dist/backstage-plugin-scaffolder-backend-module-gitlab-dynamic'
        disabled: false
EOF
----
