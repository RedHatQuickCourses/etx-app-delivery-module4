= Lab 3: Register the Template in Developer Hub
:navtitle: Lab 3: Register the Template in Developer Hub
:experimental:

In this lab, you'll register a **Software Template (Golden Path)** in Red Hat Developer Hub by configuring a catalog location. You will update the existing Developer Hub configuration and verify that the Quarkus Golden Path is available in the Software Catalog.

By the end of this lab, you will have:

* Configured a catalog location for the Software Template
* Updated the Developer Hub configuration
* Verified that the Quarkus Golden Path is registered
* Reviewed the template metadata and input form

== Configure the Software Template Catalog Location

Red Hat Developer Hub discovers Software Templates through catalog locations configured in app-config.yaml.

You'll update the existing rhdh-config ConfigMap created in the previous lab to register the Quarkus Golden Path template.

. Navigate to the OpenShift web console and switch to the **setup-rhdh** project.
+
.OpenShift Console (Click the image to view it in full size in a new browser tab)
image::ns.png[link={imagesdir}/ns.png,width=500,window=_blank]

. From the navigation menu, select Workloads → ConfigMaps.
+
.OpenShift Console Workloads (Click the image to view it in full size in a new browser tab)
image::cm.png[link={imagesdir}/cm.png,width=300,window=_blank]

. Select rhdh-config.
+
.rhdh-config ConfigMap (Click the image to view it in full size in a new browser tab)
image::rc.png[link={imagesdir}/rc.png,width=500,window=_blank]

. Select btn:[Actions] → btn:[Edit ConfigMap].
+
.Actions (Click the image to view it in full size in a new browser tab)
image::edit.png[link={imagesdir}/edit.png,width=400,window=_blank]

. Retrive GitLab URL and navigate to the GitLab account.
+
[source,bash,role=execute,subs="attributes+",role=execute]
----
GITLAB_URL="https://$(oc get route -n gitlab -l app=webservice -o jsonpath='{.items[0].spec.host}')"
echo $GITLAB_URL
----

. Add the following `catalog` section under `data.app-config.yaml` and make sure to substitute ${GITLAB_URL} value with above command output.
+
[source,yaml,subs="attributes+",role=execute]
----
catalog:
  locations:
    - type: url
      target: '${GITLAB_URL}/software-factory/golden-path-quarkus/-/blob/main/template.yaml'
      rules:
        - allow: [Template]
----
+
.Sample setting(_Click the image to view it in full size in a new browser tab_)
image::setting.png[link={imagesdir}/setting.png, width=700,window=_blank]
+
Save the ConfigMap.

NOTE: Do not replace the existing configuration. Add the template catalog location to the existing app-config.yaml settings.

== Verify the Template

Verify that the Developer Hub application has restarted successfully after the configuration change.

Wait until the Developer Hub pod returns to the **Running** state.

[source,yaml,subs="attributes+",role=execute]
----
oc get pods -n setup-rhdh -w
----

Retrieve the Developer Hub route and open the route URL in your browser:

[source,bash,role=execute]
----
oc get route backstage-rhdh \
  -n setup-rhdh \
  -o jsonpath='https://{.spec.host}{"\n"}'
----

In Developer Hub, click btn:[Catalog].

.Select Catalog (Click the image to view it in full size in a new browser tab)
image::catalog1.png[link=self,window=blank,width=300]

Select click btn:[Kind] -> click btn:[Template], you should now see the **Quarkus Golden Path** template.

.Quarkus Golden Path Template(_Click the image to view it in full size in a new browser tab_)
image::path.png[link=self,window=blank,width=600]

Select the template to verify its metadata and input form are displayed correctly.

.Template details(_Click the image to view it in full size in a new browser tab_)
image::template1.png[link=self,window=blank,width=450]

IMPORTANT: Registering a Software Template makes the Golden Path discoverable to developers through the Developer Hub Software Catalog. Developers can then use the template to create applications through a standardized self-service workflow.
