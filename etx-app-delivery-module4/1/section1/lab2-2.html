Lab 3: Register the Template in Developer Hub

Developer Hub discovers Software Templates through catalog locations configured in app-config.yaml.

Update the existing rhdh-config ConfigMap created in the previous lab.

  1. Navigate to your Openshift console, and switch to the setup-rhdh project.

    Figure 1. Openshift Console(Click the image to view it in full size in a new browser tab)

  2. Open Workloads → ConfigMaps.

    Figure 2. Openshift Console Workloads(Click the image to view it in full size in a new browser tab)

  3. Select rhdh-config.

    Figure 3. rhdh-config ConfigMap(Click the image to view it in full size in a new browser tab)

  4. Choose Actions → Edit ConfigMap.

    Figure 4. Actions(Click the image to view it in full size in a new browser tab)

  5. Retrive GitLab URL and navigate to the GitLab account.

    GITLAB_URL="https://$(oc get route -n gitlab -l app=webservice -o jsonpath='{.items[0].spec.host}')"
echo $GITLAB_URL

  6. Add the following catalog section under data.app-config.yaml and make sure to substitute <GITLAB_URL> value with above command output.

    catalog:
  locations:
    - type: url
      target: '<GITLAB_URL>/software-factory/golden-path-quarkus/-/blob/main/template.yaml'
      rules:
        - allow: [Template]
    Figure 5. Sample setting(Click the image to view it in full size in a new browser tab)

    Save the ConfigMap.

The Red Hat Developer Hub Operator automatically rolls out the updated configuration and restarts the application.

Verify the Template

Wait until the Developer Hub pod returns to the Running state.

oc get pods -n setup-rhdh -w

Retrieve the Developer Hub route and open the route URL in your browser:

oc get route backstage-rhdh \
  -n setup-rhdh \
  -o jsonpath='https://{.spec.host}{"\n"}'

Click Catalog

Figure 6. Select Catalog(Click the image to view it in full size in a new browser tab)

Select click Kind → click Template, you should now see the Quarkus Golden Path template.

Figure 7. Quarkus Golden Path Template(Click the image to view it in full size in a new browser tab)

Select the template to verify its metadata and input form are displayed correctly.

Figure 8. Template details(Click the image to view it in full size in a new browser tab)
