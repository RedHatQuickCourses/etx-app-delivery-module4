DevEx with Red Hat Developer Hub

Introduction

Welcome to this quick course on the DevEx with Red Hat Developer Hub. This course is the fourth in a series of six courses about Application Platform Delivery:

  • Introduction to Application Platforms and Platform Engineering

  • Software Factory Foundations with OpenShift Dev Spaces

  • Software Delivery with OpenShift Pipelines and GitOps

  • DevEx with Red Hat Developer Hub (This course)

  • Application Modernization with MTA

  • Trusted Software Supply Chain (TSSC) (Coming Soon)

What’s in this course?

In this course, you’ll learn how Red Hat Developer Hub provides a unified Internal Developer Portal(IDP) for a Software Factory. You’ll explore Developer Experience, Software Templates (Golden Paths), the Software Catalog, platform integrations, and OpenShift OAuth authentication to enable secure, standardized, and self-service application delivery.

Duration: 2 hours

Learning Objectives

By the end of this module, you will be able to:

  • Deploy and configure Red Hat Developer Hub on OpenShift.

  • Create and register Software Templates (Golden Paths).

  • Enable software discovery using the Software Catalog.

  • Integrate templates with platform services and development tools.

  • Configure OpenShift OAuth for secure authentication.

  • Enable self-service application creation through Developer Hub.

Prerequisites

This course assumes that you have the following prior experience:

  1. Red Hat OpenShift Container Platform (OCP) Technical Overview or Kubernetes Basics
